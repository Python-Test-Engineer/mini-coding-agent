How logging works

The agent records lifecycle transitions and sandbox audit events as JSON Lines. Follow one event from the agent loop into memory and then onto disk under logs/.

1

Agent transition

The host reaches a named lifecycle boundary.

2

workspace.record()

Builds an event and keeps it in the workspace event list.

3

EventLog.write()

Adds event details and recording timestamps to a JSON object.

4

JSONL file

Appends one serialized event per line under logs/.
