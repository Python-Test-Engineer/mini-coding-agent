How the agent sends events to the UI

The host calls a UI method with an event name and detail. The UI maps that request to labels and Rich styles in src/ui.json, then renders it in the terminal.

1

Agent host

Decides that a lifecycle, status, tool, or result should be shown.

2

UI method

Receives the event name and short detail directly from the agent.

3

ui.json

Provides configured labels and Rich styles for the event family.

4

Rich console

Renders the line, panel, code, status, or completion footer.
